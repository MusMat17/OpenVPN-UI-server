# Attach Mode — experimental
Supported: Angristan CLI installation in /etc/openvpn/server, EasyRSA PKI, one passwordless UNIX management socket, Linux amd64. No VPN daemon restart or firewall changes. Existing profiles are imported only when their embedded certificate matches the issued certificate. New profiles use the original installer, including TLS-Crypt v2. No temporary blocking or renewal yet. Do not use the native main-branch updater on this experimental build.

Build with Go 1.23: bash build.sh; then sudo bash attach-ui.sh from the repository root. Alternatively unpack the CI artifact, verify sha256sum -c SHA256SUMS, and run attach-ui.sh. Panel listens only on loopback, use SSH forwarding: ssh -L 8989:127.0.0.1:8989 user@192.168.1.100; open https://localhost:8989. Verify the self-signed certificate fingerprint locally. Back up existing VPN and PKI before using write operations. Avoid running the original installer concurrently with panel writes. Existing management socket permissions are unchanged. Only valid client-auth certificates are displayed; expired and revoked certificates are not imported. No real deployment information is included.
